## <a id="overview"></a>Overview
The Student Management System is an entry-level desktop application developed using C# and Windows Forms to streamline the administration of university student records. The project focuses on consolidating essential database operations into a cohesive, centralized workspace, eliminating the friction of navigating across multiple forms and improving overall user experience.
---
## <a id="key-features"></a>Key Features
### 🪟 Unified UI
- **Single-Window Workflow:** Centralizes core management tasks—including adding, editing, and deleting student records—within a single unified interface to avoid window clutter and streamline user navigation.
### 💳 Visual Cards
- **Simplified Data Presentation:** Implements clean, visual card layouts to display individual student information clearly at a glance.
### 👁️ Custom Views
- **Flexible Display Modes:** Provides adjustable viewing layouts (such as Details and Small Icons) directly within the table interface for tailored navigation and data inspection.
